Production Automation Architecture

"Zero-Inventory" AI Story Engine

Client: Vito Gifts  |  Role: Architect & Builder

5 Mins
Fulfillment Time
0%

100%
Automated Pipeline

Project Genesis: Conceptualized and executed a highly profitable "Zero-Inventory" digital product model. Built a fully automated, revenue-generating SaaS infrastructure entirely on Make.com. The system listens for e-commerce orders, generates dynamically illustrated personalized storybooks using dual-AI logic (LLMs + Diffusion Models), compiles them to print-ready PDFs, and delivers them directly to the customer.

Phase 1: Order Ingestion & Hero Identity Generation
Custom Webhook captures Salla e-commerce JSON payloads. GPT-4o-mini parses child attributes and outputs strict English visual prompt constraints to prevent AI hallucination and ensure character consistency.
Phase 2: Dual-Mind AI & Cinematic Rendering
A structured system prompt forces the LLM to act as "Storyteller" (Arabic text) and "Cinematographer" (English prompts). Make.com Iterator sends scenes to Leonardo.Ai dynamically with strict negative prompting for a "Pixar Up" aesthetic.
Phase 3: Compilation, Formatting & Delivery
Master JSON is mapped into print-ready HTML/CSS, converted to high-fidelity PDF via PDFShift API, uploaded to Drive, and delivered via Gmail API with signed URLs.
Self-QA & Error Handling: Implemented Break/Ignore directives and strategic Sleep functions (10-30s) within iteration loops to respect API rate limits. This robust logic prevents timeout errors during high-volume launch seasons, ensuring 95%+ server uptime.
